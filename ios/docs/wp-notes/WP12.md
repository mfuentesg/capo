## WP12 notes

- `node ios/scripts/gen-i18n.mjs` writes `Localizable.xcstrings` and `Generated/L10n.swift` (689 keys: web + `ios.*`); `--check` exits 1 when stale; `--out DIR` redirects output (testing).
- Fails on: ios keys outside the `ios.` namespace or colliding with web keys, en/es key mismatch, placeholder mismatch, keys that are not valid Swift identifier paths.
- Placeholders: one occurrence is `%@`, otherwise positional `%n$@` (index by first appearance in English). Literal `%` is escaped. No plural support yet (none in the locale files).
- `L10n` enums are `nonisolated` (CapoDesign defaults to MainActor). Swift keywords are backticked (`L10n.Filters.public`).
- Accessors are computed vars so they follow the runtime locale; funcs use `String(format:)` with String params. Namespace `ios` becomes `L10n.Ios`.
- Pre-seeded `ios.*` areas: sync, offline, demo, server, performance (shortcuts), setlist, conflict, eraseData. Wave 3: harvest `// TODO(i18n)` fallbacks.
